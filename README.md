# Speedtest

Простой CLI-скрипт для измерения скорости загрузки файла по HTTP/HTTPS.

Скрипт последовательно скачивает один и тот же файл заданное количество раз и для каждого запроса выводит:

* размер скачанных данных;
* время загрузки;
* скорость загрузки в МБ/с.

После завершения выводится общая статистика по успешным запросам.

## Требования

* Python 3.12+
* Poetry

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/bazeeff/speedtest.git
cd speedtest
```

Установить зависимости:

```bash
poetry install
```

Запустить окружение Poetry:

```bash
poetry shell
```

Либо выполнить команду напрямую через Poetry:

```bash
poetry run python speedtest.py <URL>
```

## Использование

Базовый запуск:

```bash
poetry run python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

По умолчанию выполняется **10 последовательных загрузок**.

Количество запросов можно изменить:

```bash
poetry run python speedtest.py https://proof.ovh.net/files/10Mb.dat -n 5
```

Или:

```bash
poetry run python speedtest.py https://proof.ovh.net/files/10Mb.dat --num 5
```

Таймаут одного запроса можно изменить:

```bash
poetry run python speedtest.py https://proof.ovh.net/files/10Mb.dat -t 30
```

## Пример вывода

```text
URL:      https://proof.ovh.net/files/10Mb.dat
Запросов: 3
----------------------------------------------------------------------

Запрос  1:    10.00 МБ    2.341 с      4.27 МБ/с
Запрос  2:    10.00 МБ    2.201 с      4.54 МБ/с
Запрос  3:    10.00 МБ    2.289 с      4.37 МБ/с

----------------------------------------------------------------------
Успешных запросов:     3/3
Всего скачано:         30.00 МБ
Общее время:           6.831 с
Среднее время:         2.277 с
Средняя скорость:      4.39 МБ/с
```

Если отдельный запрос завершается ошибкой, он пропускается, а остальные запросы продолжают выполняться.

Если не удалось выполнить ни одного успешного запроса, программа завершается с кодом `1`.

## Параметры

| Параметр          | Описание                             | По умолчанию |
| ----------------- | ------------------------------------ | -----------: |
| `url`             | URL файла для скачивания             |            — |
| `-n`, `--num`     | количество последовательных запросов |         `10` |
| `-t`, `--timeout` | таймаут одного запроса в секундах    |         `60` |

Пример:

```bash
poetry run python speedtest.py \
    https://proof.ovh.net/files/10Mb.dat \
    --num 10 \
    --timeout 60
```

## Зависимости

Основная внешняя зависимость:

* `requests` — выполнение HTTP/HTTPS-запросов и потоковое скачивание файла.

Зависимости проекта управляются с помощью Poetry и находятся в `pyproject.toml`.

## Особенности реализации

* Используется `requests.Session()` для повторного использования HTTP-соединения.
* Файл скачивается потоково (`stream=True`), поэтому целиком не загружается в оперативную память.
* Данные читаются блоками по `64 KiB`.
* Для измерения времени используется `time.perf_counter()`.
* Запросы выполняются последовательно.
* Ошибка одного запроса не останавливает остальные измерения.
* Для аргумента количества запросов выполняется проверка на положительное значение.
* Поддерживаются HTTP и HTTPS URL.
